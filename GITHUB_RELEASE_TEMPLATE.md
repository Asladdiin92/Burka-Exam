## 📥 Installation

### Step 1: Download
Click on `burka-exam-v1.0.0.apk` below to download

### Step 2: Install
1. Open the downloaded APK file on your Android phone
2. If prompted, allow installation from unknown sources:
   - Go to **Settings > Security**
   - Enable **Unknown Sources** or **Install Unknown Apps**
3. Tap **Install**
4. Wait for installation to complete
5. Tap **Open** to launch the app

### Step 3: Login
- Use your existing account credentials
- Or create a new account for free

## 🆘 Troubleshooting

### "App not installed" error
- Make sure you have enough storage space
- Clear previous installation if any
- Try downloading again

### "Unknown sources" blocked
1. Go to **Settings > Security**
2. Enable **Install from Unknown Sources**
3. Try installing again

### Can't login
- Check your internet connection
- Verify your credentials
- Reset password if needed

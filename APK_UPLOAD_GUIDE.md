## 🆘 Troubleshooting

### "App not installed" error
- Clear storage space (need 50MB free)
- Delete any previous version
- Restart your phone and try again

### Can't enable Unknown Sources
- Different Android versions have different settings paths
- Try: Settings > Apps > Special Access > Install Unknown Apps
- Or: Settings > Biometrics and Security > Install Unknown Apps

### App won't open
- Ensure Android version is 5.0 or higher
- Check if you have enough RAM (at least 1GB free)
- Try reinstalling
